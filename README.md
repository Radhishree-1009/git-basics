# Git and Version Control Basics

## What is Version Control?
Version control is a system that tracks changes made to files over time.
It allows us to:
- Save different versions of a project
- Restore previous versions when needed
- Work safely on projects

## What is Git?
Git is a version control tool that helps manage source code.
It records every change made to files and stores them as commits.

## Why Git is Used
- Keeps a history of code changes
- Helps avoid data loss
- Makes collaboration easier
- Allows experimenting without risk
